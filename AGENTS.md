# Portfolio development

- Work on `feature/portfolio-modernization` for this modernization. Check the active branch and working tree before editing. If a cloud task starts on a managed branch such as `work`, use the isolated checkout and create or switch to the designated feature branch. Any pull request for this work must use a separate development branch as its head.
- Never modify or push directly to `main`. Pushing any branch, merging, deploying, and dispatching the production GitHub Pages workflow each require explicit owner approval.
- Work in reviewable phases with focused, descriptive local commits. Record decisions, affected URLs, checks run, and unresolved issues. Phase 3 implements the professional portfolio foundation. Wait for owner approval before beginning Phase 4.
- Preserve the owner's research, publications, presentations, awards, photographs, and relevant academic material. Maintain existing public URLs and downloads. Verify attribution before featuring legacy material and retain the original sources for review.
- Use owner-provided or independently verifiable facts for professional claims. Never invent accomplishments, project contributions, metrics, or technical qualifications. Keep proprietary Dell information out of source, assets, previews, and documentation.
- Prefer the existing GitHub Pages pipeline, semantic HTML, shared styles, and minimal JavaScript. Add a dependency only for a demonstrated need.
- Use the [Phase 2 content inventory](.github/portfolio-content-inventory.md) for attribution, résumé and profile decisions, and publication gates. Use the [Phase 2 architecture plan](.github/portfolio-architecture-phase-2.md) for navigation, compatibility routes, and review criteria. Preserve the [Phase 1 assessment](.github/portfolio-modernization.md) and its commit `551db40`.
- Validate changes with a local Pages build served under `/mgamankwah/`. Check preserved routes and representative assets, and test navigation on desktop, mobile, and by keyboard. Follow the [rendered review procedure](.github/portfolio-architecture-phase-2.md#rendered-review-workflow) and [Phase 3 review notes](.github/portfolio-phase-3.md).
